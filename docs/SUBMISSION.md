# PinStudio
## Короткий опис тестового завдання

PinStudio — мобільний вебзастосунок за мотивами Pinterest. Можна знайти зображення, відкрити пін, зберегти його у власну колекцію та створити свою версію у вбудованому редакторі.

### Що реалізовано

П’ять екранів: стрічка з пошуком, пін, список колекцій, окрема колекція та редактор. Профіль і вхід відкриваються у діалогах.

Нова функція — простий редактор: поворот на 90°, віддзеркалення, текст, вибір пропорцій кадру. Розмір результату визначається автоматично; окремий вибір роздільності прибрано. Результат можна завантажити як PNG або зберегти окремим піном.

20 листопада редактор спрощено після повідомлення користувача про непрацездатність ефектів на телефоні. З інтерфейсу прибрано фільтри, яскравість, контраст, насиченість, масштаб і положення кадру. Рендер більше не використовує Canvas filter. Попередні відео й звіти з цими функціями описують стару версію.

### Вхід і дані

Стрічка відкрита всім за посиланням. Для особистих колекцій потрібно натиснути «Профіль» і ввійти через ChatGPT. Окремий пароль PinStudio та запрошення власника сайту не потрібні. Репозиторій поки приватний — доступ до коду надається окремо або через архів.

Сервер перевіряє власника колекцій і збережених файлів при кожному запиті. Колекції зберігаються в D1, приватні зображення — в R2. Відкриття стрічки не відкриває чужі колекції. Є перевірка Origin, ліміти файлів і захист від перезапису застарілих даних.

### API та технології

Зображення й метадані надходять із Wikimedia Commons API без ключа. Зберігаються автор, джерело та ліцензія; експорт робіт Wikimedia містить атрибуцію. Інтерфейс — HTML, CSS, JavaScript і Canvas. Сервер збирається через Vinext та Vite для Cloudflare Worker.

## Запуск і перевірка

Для перевірки на телефоні достатньо відкрити посилання в браузері. Для локального запуску потрібні Node.js 24 та інтернет. У папці з package.json виконайте:

```sh
npm ci
npm run setup
npm run dev -- --port 4173
```

Відкрийте http://127.0.0.1:4173/. Локально кнопка входу використовує тестовий акаунт Seedy без пароля. На опублікованому сайті працює справжній вхід через ChatGPT.

### AI та тести

У проєкті працювали чотири Codex-агенти: координатор, api_tests, editor_core та auth_review. Завдання розділялися за файлами й контрактами. Після інтеграції виконувалися незалежний огляд, автоматичні перевірки, збірка й браузерні сценарії. GitHub Actions повторює перевірку синтаксису, тести та збірку.

Після спрощення пройшли 50 автоматичних тестів та збірка. Тести охоплюють API, геометрію редактора, історію, колекції й ізоляцію акаунтів. Частина тестів ядра перевіряє допоміжні функції старої версії, які більше не підключені до інтерфейсу. Попередні 12 браузерних перевірок не є доказом роботи нового редактора на фізичному телефоні. Перевірка всіх мобільних браузерів не заявляється.

Основний сценарій: знайти пін → увійти → зберегти у колекцію → повернути або віддзеркалити зображення → додати текст → вибрати формат → завантажити PNG.

### Обмеження та матеріали здачі

Це навчальний проєкт, не офіційний Pinterest або Photoshop. Є один текстовий шар; немає масок, пензлів, PSD, спільних дошок та персональних рекомендацій. Збережений файл обмежений 10 МиБ. Автоматичне очищення невикористаних файлів поки не реалізовано.

Робота тривала 18–20 листопада з перервами. Точний сумарний активний час не фіксувався. Код та інструкція доступні в репозиторії. Для повної здачі потрібно надати доступ до коду та актуальне відео з коротким вступом про оригінальний Pinterest. Попереднє відео редактора після цього спрощення застаріло.
