# PinStudio

Обновление 20 ноября: редактор оставляет поворот, отражение, текст, пропорции кадра и размер до 640/1080/1600 px. Фильтры, цветовые настройки, масштаб и положение кадра удалены из интерфейса. Лента доступна всем; личные коллекции требуют входа через ChatGPT.

## Запуск на компьютере

Нужны **Node.js 24 LTS**, npm и интернет. API-ключ Wikimedia не требуется.

```sh
npm ci
npm run setup
npm run dev -- --port 4173
```

Откройте http://127.0.0.1:4173/. Команды выполняются из корня репозитория, где находится package.json. `setup` собирает Worker и применяет только ещё не выполненные миграции локальной базы. Повторный запуск безопасен для существующих данных. Для обычной работы после установки достаточно последней команды. Остановка — Ctrl+C.

Нажмите **Профиль → Войти через ChatGPT**. Только в локальном dev-режиме эта кнопка включает тестовый аккаунт **Seedy / seedy@sites.test**, без пароля и без обращения к настоящему ChatGPT. Это встроенная имитация для разработки, доступная на localhost. Локальные данные сохраняются в `.wrangler/state` и не загружаются на опубликованный сайт. Не публикуйте dev-сервер в интернет.

На опубликованном сайте действует настоящий вход через ChatGPT. Там нет общего тестового пароля. Проверяющий должен войти собственным аккаунтом. Сейчас сайт открыт для всех; GitHub-репозиторий приватный, доступ к коду нужно предоставить отдельно.

- Приложение: https://pinroom-studio-nov18-nk.toky0993.chatgpt.site
- Репозиторий: https://github.com/Tokyo993/pinroom-studio-2026-11-18

## Проверки

```sh
npm run check
npm test
npm run build
```

`check` проверяет синтаксис; `test` запускает node:test, включая серверные проверки с SQLite и имитацией R2; `build` собирает production Worker. GitHub Actions повторяет эти проверки с Node.js 24 и `npm ci`.

Для браузерного прогона установите Google Chrome и необязательный Playwright:

```sh
npm install --no-save --package-lock=false playwright
node scripts/browser-check.mjs
```

Во втором терминале должен работать dev-сервер на 4173. `BASE_URL`, `BROWSER_EXECUTABLE`, `PLAYWRIGHT_MODULE` позволяют сменить адрес, браузер и модуль. Скрипт использует реальный внешний API; сетевые ограничения Wikimedia могут повлиять на результат. Отчёт сохраняется в `work/browser-report.json`.


Подробности и ограничения: docs/SUBMISSION.md. Старые видео и браузерные отчёты относятся к предыдущему редактору.
