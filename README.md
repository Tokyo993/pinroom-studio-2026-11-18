# Pinroom

Мобильное веб-приложение по мотивам сценариев Pinterest: находить изображения, открывать пины и собирать их на досках. Новая функция — встроенная фотостудия: кадрирование, цветокоррекция, фильтры, текст и экспорт PNG.

Это самостоятельный учебный проект. Он не связан с Pinterest или Adobe и не воспроизводит все возможности их продуктов.

## Запуск

Нужен **Node.js 22 или новее**. Внешних npm-зависимостей нет; установка пакетов и API-ключ не требуются.

```sh
npm start
```

Откройте **http://127.0.0.1:4173**. Сервер привязан к локальному интерфейсу. Для загрузки ленты нужен интернет. Открытие `index.html` через `file://` не поддерживается: приложение использует ES-модули и браузерное хранилище.

```sh
npm test
npm run check
```

Первая команда запускает модульные тесты через встроенный `node:test`, вторая проверяет синтаксис JavaScript. CI-конфигурация находится в `.github/workflows/checks.yml`; локальный успешный запуск не означает, что удалённый CI уже запускался.

Для необязательного повторяемого браузерного прогона нужен установленный Google Chrome и Playwright:

```sh
npm install --no-save --package-lock=false playwright
```

В первом терминале запустите `npm start`, во втором:

```sh
node scripts/browser-check.mjs
```

При необходимости задайте `BASE_URL` и `BROWSER_EXECUTABLE` для другого адреса или пути к Chrome. Этот дополнительный скрипт прошёл 9 браузерных проверок с реальным API. Playwright нужен только для такой проверки; само веб-приложение и его обычный запуск остаются без внешних npm-зависимостей.

## Пять экранов

| Экран | Маршрут | Что работает |
| --- | --- | --- |
| Лента и поиск | `#/` | Masonry-лента, тематические категории, поиск, загрузка следующей страницы |
| Пин | `#/pin/:id` | Изображение, автор, лицензия, источник, сохранение на доску, переход в редактор |
| Мои доски | `#/boards` | Локальные коллекции и создание доски |
| Содержимое доски | `#/board/:id` | Просмотр, переименование доски, удаление пина из коллекции |
| Фотостудия | `#/edit/:id` | Редактирование изображения из ленты или собственного файла, сохранение новой версии, экспорт |

Поиск и диалоги сохранения не создают дополнительные страницы.

## Фотостудия

- Форматы кадра: оригинальный, 1:1, 4:5, 9:16 и 16:9; масштаб и смещение внутри кадра.
- Поворот на 90° и зеркальное отражение.
- Яркость, контраст и насыщенность; тёплый, прохладный, чёрно-белый и сепия-фильтры.
- Один текстовый слой: содержание, размер, цвет и положение.
- Отмена и повтор действий; удержание кнопки сравнения показывает оригинал.
- Сохранение результата отдельным пином, без замены исходного изображения.
- Экспорт PNG. Для изображений Wikimedia добавляется подпись с авторством, лицензией, источником и отметкой об изменении.

Собственное фото можно открыть кнопкой **«Создать»**. Поддерживаются JPG, PNG и WebP размером до 15 МБ. Рабочее изображение ограничено длинной стороной 1600 px; подпись источника может дополнительно увеличить высоту экспортируемого PNG.

## Архитектура

Приложение написано на нативных HTML, CSS и JavaScript ES modules. Сборщик, сервер приложений и база данных на сервере не нужны. Статические файлы из `dist/` готовы к размещению на HTTPS-хостинге.

```text
dist/
  index.html       оболочка, метаданные и CSP
  style.css        адаптивный интерфейс
  app.js           маршруты, взаимодействия, Canvas-редактор
  api.js           адаптер Wikimedia Commons
  editor-core.js   чистая математика редактора и история
  storage.js       IndexedDB и операции с коллекциями
scripts/serve.mjs   локальный статический сервер
tests/             модульные тесты
docs/              описание сдачи и сценарий демонстрации
```

Внешний источник — [Wikimedia Commons Action API](https://www.mediawiki.org/wiki/API:Imageinfo). Поиск запрашивает 24 результата за страницу, метаданные и уменьшенные изображения. API-модуль проверяет URL, приводит метаданные к тексту, обрабатывает ошибки, отмену и тайм-ауты. Кэш результатов живёт в памяти вкладки до пяти минут. Поиск обычно лучше работает с английскими словами: `mountains`, `flowers`, `architecture`.

## Данные и приватность

Доски, сохранённые пины и результаты редактирования находятся в **IndexedDB этого браузера**. Собственные фотографии обрабатываются через Canvas на устройстве и не загружаются на сервер. Аккаунтов, облачной синхронизации и публичных пользовательских досок нет.

Хранилище изолировано браузером по origin, но **не зашифровано и не защищено от другого человека, использующего тот же профиль браузера**. Очистка данных сайта удаляет коллекцию. Важные результаты следует экспортировать. При обращении к Wikimedia сервис получает поисковый запрос и IP-адрес; запросы выполняются без учётных cookies. Содержимое досок не передаётся Wikimedia.

CSP ограничивает источники скриптов, изображений и сетевых запросов. API-строки экранируются при отображении; URL проходят проверку схемы и разрешённых хостов. Загружаются только поддерживаемые растровые форматы. В проекте нет секретных API-ключей. CSP допускает inline-стили, которые используются для соотношения сторон карточек, но не inline-скрипты.

У изображений сохраняются автор, исходная страница и лицензия. Условия конкретной работы доступны по ссылке источника; наличие функции экспорта не отменяет эти условия.

## Проверки и ограничения

Прошли **26 модульных тестов**, проверка синтаксиса и **17 браузерных проверок** через автоматизацию Chrome/Playwright. Проверены геометрия кадрирования, история изменений, адаптер API и операции с коллекциями. Настоящий API вернул HTTP 200 и 24 изображения. Браузерный прогон проверил сохранение в IndexedDB после перезагрузки, поиск с экрана доски, фактическое изменение пикселей фильтром, кадр 4:5, восстановление пикселей при отмене/повторе, сохранение черновика при навигации, валидную PNG-сигнатуру экспорта и независимость новой версии от оригинала. Также проверены загрузка собственного файла, его сохранение, переименование и удаление пина. Проверены ширины 1440, 390 и 320 px; на узких экранах нет горизонтального переполнения. Необработанных браузерных ошибок не зафиксировано. Подробные отчёты: `browser-report.json` и `extra-browser-report.json` в комплекте результатов.

Независимый обзор выявил и помог исправить поиск при переходе с другого маршрута, потерю черновика при навигации, конкурирующие удаления, переход по ссылке доступности и переполнение заголовка на ширине 320 px. Последняя успешная проверка относится к исправленной версии. Удалённый CI ещё не подтверждён.

Ограничения: один текстовый слой до 120 символов, история до 40 состояний, нет кистей/масок/выделения объектов/PSD, нет персональной рекомендательной модели. Черновик редактора сохраняется при переходах внутри открытой вкладки, но не после её перезагрузки. Несохранённое загруженное фото также живёт только во вкладке. Лимиты и временная недоступность Wikimedia могут мешать поиску или открытию изображения. Ёмкость коллекции ограничена квотой браузера. Одновременное редактирование коллекции в нескольких вкладках не синхронизируется: последняя запись может заменить изменения другой вкладки. Интерфейс — на русском языке.
